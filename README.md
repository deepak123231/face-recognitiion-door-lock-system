# face-recognitiion-door-lock-system
This Project is about face recognition door lock system using OpenCv and Arduino uno
OpenCV (cv2)

For image/video processing, face detection, and camera handling.

Install: pip install opencv-python

face_recognition

Built on top of dlib. It simplifies face recognition, encoding, and matching.

Install: pip install face_recognition

dlib

Underlying library used for face detection and facial landmark prediction.
